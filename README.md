# fat-git

FatNotes 工作区的 Git 插件。版本库就建在宿主当前打开的工作区目录上，用来管理书籍、配置、思维流这些文件。

## 能做什么

- **变更**：暂存、取消暂存、丢弃、提交，以及查看单个文件的差异。有远程时可以获取、快进拉取和推送。
- **提交图**：按时间从新到旧画出分支泳道，点开提交可以看说明和文件差异。
- **分支**：创建、切换、删除本地分支，检出远程分支。
- **仓库信息**：工作区路径、Git 版本、提交身份、远程地址，以及 `.gitignore`。
- **自动提交**：按分钟间隔把工作区改动提交进去。默认关闭。数据库目录 `dbs/`、依赖和构建产物默认排除。索引里已经有暂存时，这一轮会跳过。

底部状态栏会显示当前分支和改动数量。

## 使用前

系统里需要能在 PATH 中运行 `git`。初始化仓库时，如果还没有 `.gitignore`，会写一份默认忽略规则。提交身份只写进当前仓库，不改 Git 全局配置。

## 开发

```bash
npm install
npm run dev
```

在 FatNotes 里把插件的开发目录指到本项目的 `dist`。`plugin.json` 里的 id 会作为插件 id，避免模块联邦名称对不上。

生产包：

```bash
npm run build
```
